# PRAKTEK GIT

## Inisialisasi GIT

```bash
$ git init
```

## Interim Changing (Staging)

Menyimpan perubahan sementara dari working directory ke dalam staging area

```bash
$ git add <...dir_file>
$ git add >...dir_folder>
```

## Permanent Changing (commit)

Menyimpan seluruh staging menjadi permanen

```bash
$ git commit
$ git commit -m "<commit-name>"
```
